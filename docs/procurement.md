## 超预算时交给用户选择

当前完成采购前软件与方案核验，不代购。下一步核对同SKU、成品接头、配件、运费及电脑转接器的完整结算金额。
如果最低可行购物篮超过300元、关键SKU难买或需要更换板卡，先列出真实报价与能力差异，等用户决定；不擅自加预算、换板或删数据项。

| 选择 | 数据能力与工作变化 | 预算判断 |
| --- | --- | --- |
| 完整主方案 | 温湿度、光照、相对声音；一条Grove线与四根跳线；保留完整第一阶段范围 | 目标290，最终全部费用≤300即可按原预算推进 |
| 预算增加最多50元 | 仍可选完整主方案，差价用于真实运费、合格电源、固定件或缺货差价；不强制增加数据项 | 仅用户决定后启用300–350范围；多花50元不会自动提高传感器精度 |
| 先温湿度与声音，光照下一次补 | 暂缓购买U136，少一条Grove线；光照通道明确未安装，不能分析亮灯因素；后续插回即可 | 按预算表减50元，约240元；具体节省以报价为准 |

| 无品牌ESP32+裸INMP441/SHT/BH1750 | 可能更便宜，但预焊状态、电平、针序与不同卖家板型难一致；当前已有低成本成品路线，不增加新手核板负担 |
