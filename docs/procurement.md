## 安装与电脑配件

硬件接线只按[硬件方案](plans/hardware.md)的最新引脚表执行；刷写/配置按[运行手册](operations.md)。
概念连接为：

```text
C008-C底部3V3/GND/G21/G25
  → 4根公公跳线 → 分线模块附线 → DFR0759
                                  ├─ 温湿度附线 → SEN0528
                                  └─ 光照附线   → SEN0228
```

两传感器共用3.3V和一条I²C总线。按实物信号标签逐根核对，不凭颜色猜引脚；不能把3V3误接相邻5V。
相比原方案增加一个小分线模块，仍只需4根逐根插接的跳线；其余用各模块附带的成品连接线，无焊接、剥线、压接或裸线缠绕。

当前电脑的USB接口均为USB-C/雷雳，没有USB-A；[Apple规格](https://www.apple.com.cn/macbook-pro/specs/)支持此判断。
刷写：电脑USB-C → 30175转接线 → FIT0641数据线 → C008-C。
夜间：50714电源USB-A → 同一根FIT0641 → C008-C。
不要买反方向的USB-A公→USB-C母转接头，例如绿联50533；数据线必须支持传输，纯充电线不能刷写。
无需电脑扩展坞、面包板、外置麦克风、屏幕、电池、SD卡或焊接工具。此处的DFR0759是传感器分线模块，不是USB扩展坞。
