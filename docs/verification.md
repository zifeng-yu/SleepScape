## 能展示什么

| 内容 | 已核验行为 |
| --- | --- |
| 睡眠时长、平均心率、HRV | 取专属原文字段，不以日均或静息心率替代；有来源、单位、抓取时间和暂定状态 |
| 昨日负荷与近月变化 | 读取完整历史基线；日常只回查7日不会缩小展示分母；缺失不补0 |
| 心率与HRV时序 | 按UTC裁剪并以Asia/Shanghai展示；缺口不插值，提示实际样本时刻与距光标时间 |
| SpO2与Body Battery | 小时聚合/稀疏点分开标记，不生成分钟级连续曲线 |
| 压力、步数、呼吸与睡眠评分 | 有字段才展示，日统计不伪装夜间时序 |
| 活动与午睡 | 独立事件，可查看摘要并定位时间轴；API不暴露GPS、owner或原始活动ID |
| 睡眠分期 | 7/7日无区间，展示睡眠窗口和阶段累计，并明确标注无分期时间线 |

阶段累计可能按分钟取整、总睡眠量保留秒。只有满足严格取整特征时标记精度提示，原值不变；其他差异继续告警。
本轮未知阶段差异0。样本数量不等于连续时间覆盖率，预期原生频率未独立确认，覆盖率保持空值。

## 硬件与采购方案资料核验

本轮没有重新拉取Garmin数据，没有修改数据库、凭据或运行服务。当前结论是“设计条件通过”，不代表硬件链路已经运行。

| 核验项 | 结果与证据位置 |
| --- | --- |
| 研究与范围 | 温度/湿度、光照、相对声音有相关实验依据；作为成本与可测性选择，不声称普适影响排名；原始论文链接在硬件方案 |
| 主BOM | C008-C + SEN0528 + U136；麦克风集成，Gravity附线加4根公公跳线、Grove附线，免焊；官方产品/原理图及接头照片已核 |
| 电气与适配 | AHT20走底部3.3V/G21/G25独立I²C，DLight走Grove26/32；不与PDM33/23冲突；无需Hub；原理图和驱动入口可追溯 |
| 采购与预算 | 优先M5官方淘宝店和DFRobot中国商城；AHT20页面参考35元，整套290元为预算分配；淘宝两件现货/价格与最终结算尚未确认 |
| 发现并纠正的风险 | ENVIII上拉电平疑点撤出主BOM；ENVPro全Grove约400元只作为备选；未用进口标价假装国内到手价 |
| 程序连续性 | 固件→分钟/事件→独立认证POST→事务/幂等ACK→独立环境表→UTC视图→指标注册表；补齐现有全局只读门禁与四表备份校验的改造点 |
| 时间和质量 | 无RTC冷启无网保留unknown；同boot锚点独立映射；逐通道覆盖，配置断点，PCM不落盘/上传，dBFS不冒充dBA |
| 容量模型 | 48小时本地模型868,352B；1年525,600分钟；有界分钟/事件载荷模型约0.80GB/年，索引等另计；是公式核对，不是固件或云端压测 |
| 预算决策 | 基础方案实际总价若超300元，列完整/延后光照/提高预算/暂缓对照给用户选择，不自行扩支 |
| 尚未通过 | 完整固件编译、实物接线/写入、连续与48小时故障验收、真实数据对齐、2核2G云端负载和年度存储增长 |
