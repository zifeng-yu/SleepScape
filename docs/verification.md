## 设备选片方案核验（2026-11-24）

**结论：候选规则能在部分合成输入中选中目标，现行云端合同允许上传较晚胜出的片段。** 合成复核发现秒边界漏检、干扰抢占及睡前耗尽配额均可能遗漏目标。设备选片原型暂缓。[硬件方案与放行条件](plans/hardware.md#设备按频段变化选择回听片段)

**现有样机首次已知声源对照。** 用户现场听到测试音的全部重复音组，并报告最后一组的大致时刻。按文件内固定间隔回推，云端对应分钟声音采集完整、检测器就绪，无 DMA 溢出或削顶。测试及相邻对照时段均无声音事件，独立音频库也无对应片段收据。目标附近分钟的最高一秒电平高于前面的背景分钟；当前仅有分钟聚合，时间映射为估算，无法将峰值逐秒归属于测试音。

**同一测试音第二轮。** 按用户提供的起播时刻与文件内间隔核对。首组所在分钟声音缺秒、检测覆盖不完整；第二组所在分钟采集和检测覆盖完整，未触发。末组预期时段内有事件，并有同一设备、启动周期和序号的片段暂存收据。起播前另有环境事件，未计入测试命中。三组所在分钟均无 DMA 溢出或削顶。两轮都有检测覆盖完整而未触发的目标；末组只能确认时间吻合，片段内容与可辨性未经试听。用户确认两轮播放条件相同，使用同一设备、同一音量近距离播放。两轮属于同条件重复测试，无法从中估计距离的影响。

**已知音乐原声试听。** 用户播放音乐后，指定该时段的单个事件片段下载到本机试听，并确认听到的正是当时播放的音乐。

**自然夜间片段原声与增强对照。** 连续选取已发布片段，用户试听同一段原声及高通后加受限增益的版本。听成噪音的片段增强后仍是噪音；一段可辨为关门声，增强后只觉得更响。此次没有新增可辨内容。回看原声，几段整体电平相近，关门声片段在 80 Hz 高通后保留的电平明显高于噪音片段。按剩余电平排序时，已知的关门声排在前面。其余未参与本轮试听的同夜片段在两种规则下的相对顺序一致，无法据此验证哪种排序更好。多夜盲听条件见[剩余计划](plans/completion.md)。

- **对照方法。** 临时 C 驱动链接仓库的 `sc_core.c` 与 0.4.0 `sc_clip.c`，向两条路径输入相同的 16 kHz、16 位合成样本。用生产 PCM 聚合和事件检测，旧版直接执行选片与上传回调，以替身提供充足堆和及时取包；候选使用独立主机试算，按检测器最终事件秒评分。在 185 秒序列中以 300 Hz、峰值 80 个 PCM 计数为背景，默认在第 65 和 75 秒分别插入一秒目标或干扰，两端各用约 20 ms 半余弦渐变。典型低频扰动为 5 Hz / 6000 计数，测试音为 1 kHz / 1400 计数。参数在本轮固定。
- **13 组合成情形。** 低频在先时旧版取第 65 秒，候选取第 75 秒的测试音；颠倒顺序后两者均取测试音。仅有低频扰动时旧版有片、候选无片；纯背景均无片。120 Hz 的合格低音目标也可被选中。同分留早、缺样后重新暖机、相邻分钟独立选择和单段时长上限符合候选预期。跨分钟试算假定有可用缓冲，真实上传忙碌时的取舍须在固件集成验证。
- **反例。** 较弱测试音、强低频背景掩蔽的测试音均未触发原检测器，两版都选不到。较强的 250 Hz 干扰可胜过随后较弱的 1 kHz 目标。长事件中后到的更强一秒会替换已有较长片段。这些结果限制了按频段变化选片所能承诺的可辨性。
- **协议核对。** 使用合成服务的生产 POST、事件记录与裁剪程序：同一合并摘要内活动时段为第 65 和 75 秒，上传后一个位置的胜出包，重复请求成功；再上传前一个不同包返回 422 并保留原包。定稿前不可播放。合成睡眠窗口收窄后，播放样本数与预期裁剪一致，进一步收窄到片段外后不可播放并按现有流程清理。另运行 `pytest tests/test_event_audio.py`，现行三项回归通过。本轮仅在主机及临时合成库执行，ESP32 堆、实时覆盖、真实麦克风与盲听改善待验。

**面向实际听感的补充复核。** 主机临时驱动用生产 `sc_pcm_add/finish` 和 `sc_events_step` 处理 16 kHz 合成 PCM，评分端模拟现有相邻样本平均及提案的连续高通、背景和门槛。以下幅度为有符号 16 位样本的峰值计数。固定背景为 300 Hz、峰值 80；测试音按所列起点和时长叠加。全部输入均为合成，未录取现场声音。

## 看板回听模式切换（2026-11-24）

看板默认播放原声，可对同一已发布片段切到“减弱低频”。合成浏览器用含 20 Hz 和 1 kHz 两种音调的 WAV，从实际媒体源检查音频节点连接与频率响应：高通在 20 Hz 的幅度增益小于 0.07，在 80 Hz 约为 0.707，在 1 kHz 约为 1。切回原声后媒体源直接连接播放输出。

在 320 px 视口核对点击播放前无音频请求、播放中往返切换继续前进、暂停后改模式再继续、隐藏事件时停止播放。切换未新增音频请求，关联记录面板没有横向溢出。浏览器以 `demo=true` 的合成服务验收。真机手机的操作和播放表现仍待专项核验。

## 容量与故障恢复基线

### 48小时缓存实测
