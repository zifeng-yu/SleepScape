# 睡眠解读

逐夜报告回答目标夜睡得怎样、哪些现象可能与睡感有关。日任务核验数据资格，按睡眠窗口对齐佳明与环境观测，并附上已填写的晨起睡感。模型结合这些来源解释客观记录和个人体验的异同，也说明证据的局限。正文仅按 JSON Schema 验收。

## 7 日复盘总结

七日复盘解读整个实际窗口。逐晚发送观测数据、测量上下文及可选晨起睡感，由模型归纳跨夜规律、变化和例外，区分有多晚支持的发现与孤立现象。窗口以醒来日排序，截止日仅用于选定范围。短窗口如实标明可观察的晚数。逐夜与七日分别使用独立提示词，正文共用 JSON Schema。
