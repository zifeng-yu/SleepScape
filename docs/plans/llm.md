# 睡眠解读

逐夜报告回答目标夜睡得怎样、哪些现象可能与睡感有关。日任务核验数据资格，按睡眠窗口对齐佳明与环境观测，并附上已填写的晨起睡感。模型结合这些来源解释客观记录和个人体验的异同，也说明证据的局限。正文仅按 JSON Schema 验收。

## 7 日复盘总结

七日复盘同样解读目标夜，另加入之前最多六晚的同口径观测供比较。窗口以醒来日排序，最后一晚为目标夜，实际起点受看板展示起点限制。
