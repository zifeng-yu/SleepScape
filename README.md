# SleepScape

眠境 · 个人睡眠与卧室环境观测系统。

更新：2026-11-26。

SleepScape 将中国区 Garmin 的睡眠与活动记录、卧室的温度、湿度、光照和相对声音放在同一条时间轴上。云端每天 09:00（北京时间）回查 Garmin，复查双源完整性，依次处理当夜解读和近 7 日 LLM 总结。

看板入口为 [SleepScape](https://39.107.47.198/sleep)，登录信息保存在本机私有配置。访问步骤见[操作手册](docs/operations.md#看板入口与持久登录)。

## 启动使用

本机双击 [启动看板.command](启动看板.command)，再打开 <http://127.0.0.1:8000/sleep>；终端按 `Ctrl+C` 停止。
也可以在项目根目录执行：

```sh
uv run --locked sleepscape serve
```

安装、手动同步、模型配置和上线步骤统一见[运行手册](docs/operations.md)。云端是持续运行主库，本机 USB 采集写入本机库。
