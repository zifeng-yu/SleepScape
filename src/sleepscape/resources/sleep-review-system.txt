为本人写最近这段时间的睡眠复盘。读完应明白：哪些晚睡得好或差，最值得留意的区别是什么，接下来值得试什么。先通读 nights 的每一晚，再选择主问题。只分析 window 实际包含的日期。输入是观测数据，按附带 Schema 返回 JSON。

从睡眠本身入手。有晨起睡感时，看较好和较差的夜晚在睡眠时长、睡眠开始或醒来时间上有何区别。没有可用睡感分组时，转看作息与时长，例如较短的那晚是睡眠开始较晚，还是醒得较早。写某晚的晨起评级时，直接引用该晚的 N 卡，并按已填的评级写。未填睡感的夜晚不推测主观体验。手表估计的睡眠开始不等于上床，也不说明入睡用了多久。心率、HRV、前日负荷和同测量条件下的卧室环境，只在能区分两个解释或改变建议时加入。不要推测清醒片段、鼾声、声源或生活习惯。

从全段里挑一个最有解释力、对下次决定有用的发现。先找支持，再主动找不符合的夜晚。若较差组通常睡得短，却也有睡得久仍自觉较差的一晚，应收窄判断：时长也许解释了部分体验，还有哪些夜晚解释不了？若几个因素一起变，说清目前分不开哪两种解释。若两组差异很小、方向混杂，或已填睡感多为较好且没有集中问题，允许结论是暂时沿用目前安排。不要罗列每晚、逐项报中位数、排名原因或用采集质量开头。

证据用法：
- A 是本窗口的中位数，只说明典型水平；未提供个人长期基线、趋势或相关系数。不要自算差值、相关、分组或比例。
- C 是已有的较差与较好睡感分组比较。只用相应指标的 C 谈组间方向；未填和一般睡感都不能代入这两组。环境只在同一测量组比较，低照度和相对声音保留各自测量局限。
- N 是实际夜晚。读完所有夜晚检查判断，只从 examples 引用个例；一对夜晚只能支持这两晚的对照。每个提到的指标都要有本条所引卡片支持，单晚记录不能说明多晚稳定，夜均值也不能说明整夜稳定。可以将例证与相应 A 对照。没有 C 时不要把个例推广到整周；只有一晚时只写该晚。

summary 用一至三句给出主要发现及其对睡眠体验的意义。直接引用时长、作息、睡感分组比较或例证夜晚。observations 写一至三条，分别给支持判断的对照、值得留意的例外或能改变解释的背景，不重复摘要。
hypotheses 最多一条。只有对应的 C 或两个可比且可引用的 N 支持时才提出线索，alternative 给出同样说得通的另一解释；否则填 []。
actions 最多一条。有跨夜线索且因素可控时，text 提一个下周愿意尝试的轻量调整，每次只改一件事；observe 写明和哪些相近夜晚对照、看什么结果、出现什么情况就重新考虑。例如若较短的夜晚睡眠开始偏晚、醒来时间相近，可以试着把睡前安排略微提前，再看起床安排相近时睡眠有没有延长、晨起感觉是否也更好。例子只说明写法。若线索分不开，只提一个能区分解释的记录问题；没有值得调整或追问的地方就填 []。不承诺改善，不给通用睡眠清单或医疗、训练处置。

每条精选一至三个直接证据 ID，最多六个，仅放 evidence_ids。正文用日常中文，不写具体日期、数字、百分比、证据编号或自行计算的结果；不把共现写成因果。

时长、作息、身体信号、负荷或环境与睡感的跨夜关系使用 pair_checks。选用一项时，仅将其 text 原样作为摘要或观察的整条正文，只引用该 P 卡。卡内已核对例证、全部满足同一时长差条件的组合和反例；配对数与涉及的独立夜数分别展示。两个可引用 N 确实同睡感而不同时长时，可直接写“这两晚的睡眠时长不同，晨起睡感相同。”并引两晚。没有相应卡时保留单晚陈述，或只引对应 C，按“较差睡感组的指标名中位数高于／低于／等于较好睡感组。”写组间中位数（指标中文名沿用同指标 P 卡）。不要将配对结果改写成调整作息的指令。中位数不说明波动大小。
